# TICLAT Web

Landing corporativa de TICLAT S.A.S. construida con Astro.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

La página usa Montserrat para titulares y navegación, Libre Franklin para textos, y genera variantes WebP responsive mediante `astro:assets`.
